# 🛰️ AdaLink

## Afro-Conect Inteligente

### 🌍 Visão do projeto

O AdaLink é um projeto de pesquisa e desenvolvimento voltado à criação de novas formas inteligentes de conectividade, investigando a utilização de informações provenientes de sistemas de navegação por satélite (GNSS) e tecnologias de comunicação não terrestre (NTN).

### 🎯 Objetivo

Investigar e desenvolver uma camada inteligente capaz de analisar informações disponíveis ao dispositivo e identificar possibilidades de conectividade satelital.

### 🔬 Primeira fase

A primeira fase consiste em estudar:

- GNSS/GPS
- sinais recebidos pelo smartphone
- informações orbitais
- tecnologias NTN
- comunicação Direct-to-Device (D2D)
- limitações do hardware do smartphone
- possíveis arquiteturas de comunicação

### 🧠 Princípio

> Aproveitar inteligentemente aquilo que o dispositivo já consegue receber do espaço e investigar novas possibilidades de comunicação.

### ⚠️ Importante

O projeto não busca invadir, quebrar ou contornar sistemas de comunicação. A pesquisa será voltada ao desenvolvimento de soluções técnicas legítimas.
